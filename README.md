# homebrew-tap

Personal [Homebrew](https://brew.sh) tap.

## Usage

```sh
brew install bogdankim/tap/encore
brew install --cask bogdankim/tap/clickraise
```

## Formulae

| Formula | Description |
| ------- | ----------- |
| [`encore`](Formula/encore.rb) | Fast terminal client for Apple Music on macOS |

## Casks

| Cask | Description |
| ---- | ----------- |
| [`clickraise`](Casks/clickraise.rb) | Windows-style click-to-raise for macOS |
